# cs122-cafe-management
## Setup
1. In the project root, create a virtual environment by running:

    ```python3 -m venv .venv``` 

    or

    ```python -m venv .venv``` depending on your python version. 


2. Activate the virtual environment:

    ```source .venv/bin/activate```


3. Install the required dependencies:

    ```pip install -r requirements.txt```


4. Run database.py to create and initialize the database:

    ```python3 database.py```

    or

    ```python database.py```
